# 真实边界

与 `laowang-jianli`（可选联动，需另行安装） 对齐：

| 状态 | 写法 |
|------|------|
| 简历有明确事实 | 可写进口述稿 |
| 合理归纳 | 稿中可写，session frontmatter 标 `inferred` |
| 缺数据 | 标 `[待补数据]`，兜底句说明 |
| 无证据 | 标 `[无证据，勿硬答]`，不写进正式答稿 |

**口述稿禁止**：
- 新造转化率、用户量、排名
- 把「参与」说成「主导」
- 把课程作业说成「上线产品」
- 为迎合 JD 编造「热爱 XX 业务」（除非简历/素材有依据）

**合并总册时**：从旧 session 带进新章的内容，必须重新核对当前简历版本。
